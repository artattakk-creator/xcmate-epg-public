# GS Media EPG fallback artwork v1

Six original, procedurally drawn 960×540 PNG backgrounds: news, sports, movies, series, documentary and universal. No third-party images, logos or text. Created for reuse as fallback artwork in GS Media EPG Hub and XCMate. Keep these versioned files separate from rotating EPG releases. Use the universal image for unknown categories. These graphics do not represent actual programme scenes. The application must retain local fallbacks for offline operation.

See `manifest.json` for file names and Git blob IDs.
