# GS Media EPG fallback artwork v1

Six AI-generated cinematic PNG backgrounds (1672 × 941 pixels, approximately 16:9): news, sports, movies, series, documentary and universal. Created for GS Media EPG Hub and XCMate, with a stylized XMate emblem. These images are category placeholders, not actual programme scenes.

The original filenames and directory are retained for URL compatibility. Assets are separate from rotating XMLTV releases. Use the universal image for unknown categories and keep local copies for offline fallback.

See `manifest.json` for dimensions, file sizes, Git blob IDs and SHA-256 checksums.
